# 🦊 책 먹는 여우 (Book-Eating Fox) for SillyTavern

채팅을 한 권의 책처럼 읽게 해주는 확장입니다. 책갈피, 리디 스타일 독서노트, 챕터와 목차, 채팅 검색, 독서 통계, 명대사 카드, 내보내기를 여우가 챙겨줍니다.
외부 라이브러리 없이 파일 3개로 만들었습니다. 따로 웹폰트를 받지 않고, 쓰고 있는 테마(SillyTavern 테마, 블루 레몬에이드 같은 테마 확장)의 글꼴과 글자 크기를 그대로 따라갑니다. 노트 인용문과 명대사 카드는 채팅 본문과 같은 글꼴로 보여요.

## 설치

**SillyTavern 확장 설치 기능으로 (추천)**

1. SillyTavern 위쪽 메뉴의 **확장(퍼즐 조각) → Install extension**을 누르세요.
2. 아래 주소를 붙여 넣고 **Install**(관리자 계정이면 Install just for me)를 누르세요.
   ```
   https://github.com/sdafaff346/bookeatingfox.git
   ```
3. 설치가 끝나면 새로고침하고, **마법봉 메뉴 → 책 먹는 여우**로 패널을 여세요.
4. 업데이트는 확장 관리(Manage extensions)에서 책 먹는 여우 옆 업데이트 버튼으로 할 수 있어요.

**직접 넣기**

1. [GitHub 저장소](https://github.com/sdafaff346/bookeatingfox)에서 Code → Download ZIP으로 받아 압축을 푸세요.
2. 폴더를 통째로 `SillyTavern/data/default-user/extensions/`(내 계정만) 또는 `SillyTavern/public/scripts/extensions/third-party/`(모든 사용자)에 넣고 새로고침하세요.

예전 `SillyTavern-Bookshelf`(책갈피) 폴더가 있다면 지우세요. 저장된 책갈피와 노트는 그대로 이어집니다.

## 패널 열기와 옮기기

- 입력창 왼쪽 **마법봉 메뉴 → 책 먹는 여우**를 누르면 패널이 열려요. (`/bookfox`로도 열 수 있어요)
- **PC**: 패널 윗부분을 끌어서 옮기고, 오른쪽 아래 모서리를 끌어서 크기를 바꿔요. 윗부분을 더블클릭하면 원래 자리로 돌아가요.
- **모바일**: 화면 전체를 쓰는 창으로 열려요. 왼쪽 위 ‹ 버튼으로 채팅으로 돌아가고, 목록에서 항목을 누르면 창이 닫히면서 그 메시지로 이동해요.
- 위치와 크기는 기억돼요. 설정의 "패널 위치·크기 초기화" 버튼으로 되돌릴 수 있어요.

## 기능

| 하고 싶은 것 | 방법 |
|---|---|
| 책갈피 | 메시지 `⋯` → 🔖 버튼 (다시 누르면 빼기) · `/bm 이름` |
| 형광펜 | 채팅에서 문장이나 문단을 드래그한 뒤 색 선택 (채팅에 보이는 줄바꿈·문단 나눔 그대로 저장돼요) |
| 형광펜 없이 메모 | 드래그한 뒤 **메모** 선택. 메시지 전체에 메모하려면 `⋯` → 📝 |
| 형광펜 색 바꾸기 / 지우기 | 칠한 문장을 누르세요 (⌀ = 형광펜 없이 메모만 남기기) |
| 메모 표시 | 메모가 달린 문장엔 주황 점선 밑줄이 생겨요. 글자 위에 겹치지 않아서 따옴표(” " 」)도 가리지 않고, 줄바꿈도 그대로예요 |
| 챕터 시작 | 메시지 `⋯` → 📖 버튼, 또는 목차 탭에서 추가 |
| 명대사 카드 | 드래그 → **카드**, 또는 메시지 `⋯` → ❝. 디자인 10가지: **밑줄**(리딩 앱처럼 형광펜이 그어진 문장, 노트의 형광펜 색 그대로), **책 한 쪽**(책 한 페이지 · 머리말 · 쪽 번호), **미니멀**(테두리 안 가운데 정렬), **편지지**(줄 노트 위 손편지 · 여우 우표), **폴라로이드**(캐릭터 사진을 테이프로 붙인 사진 + 문장), **메모지**(책상 위 포스트잇), **자막**(캐릭터 사진 위 영화 자막), **말풍선**(메신저 화면처럼 · 보낸 시각), **포스터**(큰 글씨), **커뮤 반응**. 디자인마다 색을 고르고, 크기는 **4:5 피드 / 1:1 / 9:16 스토리**. 짧은 문장은 글자가 커지고 긴 문장은 알아서 작아져요(폴라로이드는 사진이 작아지며 자리를 내줘요). 화자 이름 · 캐릭터 이름(제목) · 챕터 · 프로필 사진 · 쪽수 · 여우 도장은 켜고 끌 수 있어요. 편집 창에서 디자인마다 지금 문장이 들어간 미리보기를 보여 줘요. **원문 줄바꿈 / 문장마다 / 한 문단** 버튼으로 줄을 정리해요 |
| 이름 가리기 (테이프) | 카드 편집 창의 **이름 가리기** 칸에 가릴 단어를 쉼표로 적으면(예: `패트릭, 엘리`) 카드에 그려지는 글자 중 그 단어만 테이프로 덮어요. "패트릭은 심심했다" → 패트릭만 가려지고 "은 심심했다"는 그대로. 본문·화자·제목·챕터·댓글 어디든, 카드 여러 장·챕터 요약·독서 기록 카드에도 똑같이 들어가요. 테이프는 크래프트 / 도트 / 줄무늬 / 체크(끝이 찢어진 와시테이프) · 검정 펜 · 수정테이프 중에서 골라요. 지금 캐릭터와 내 이름은 버튼 하나로 넣을 수 있어요 |
| 원문 + 번역 카드 | 카드의 **번역** 칸에 번역 문장을 적으면 원문 아래(또는 위)에 작게 함께 들어가요. 실리태번 번역 기능을 쓰는 메시지는 **메시지의 다른 언어 불러오기**로 한 번에 채워요. 번역은 노트에도 저장돼 목록·내보내기에 같이 나와요 |
| 커뮤 반응 카드 | 카드 디자인에서 **커뮤 반응**(밝게 / 어둡게)을 고르면 명대사가 게시판 인기글처럼 그려져요. 추천 수, 조회수, BEST 댓글이 붙고, **글 제목과 댓글은 직접 고칠 수 있어요** (한 줄에 하나, 4개까지). 🎲 **다시 뽑기**로 제목·댓글·숫자를 새로 뽑아요. 대사가 길면 댓글 수가 알아서 줄어요 |
| 숨긴 메시지 검색 | 검색 탭의 범위 칸에서 **숨김 포함**(보이는 메시지 + 숨김 표시한 메시지, 기본) · **숨김 빼고** · **숨김만**을 골라요. 숨긴 메시지 결과엔 👁‍🗨 **숨김** 표시가 붙고, 누르면 그 메시지로 이동해요. 고른 범위는 기억돼요 |
| 먼 옛날 메시지 미리 읽기 | 지금 보는 곳에서 60개 넘게 떨어진 메시지(아직 안 불러온 것도, 이미 불러온 것도)를 누르면 먼저 **미리 읽기 창**에서 바로 보여 줘요. 접힌 답변은 펼쳐지고 검색어엔 표시가 붙어요. HTML 화면 답변은 그려서 보여 줘요. **채팅에서 그 위치로 가기**를 누르면 실제 위치로 가요. 설정에서 끌 수 있어요 |
| 흔들리지 않는 이동 | 이동하는 동안과 도착한 뒤에는 다른 확장·테마·프런트엔드가 채팅을 맨 아래로 끌어내리려 해도 막고, 메시지가 다시 그려지거나 지워져도 다시 찾아가요. 직접 스크롤하거나 글을 쓰면 바로 손을 놔요. 이상하면 설정의 **마지막 이동 기록 보기**(또는 `/bookfox debug`)로 원인을 볼 수 있어요 |
| QR · 접힌 답변 검색 | 빠른 답장(QR)이 `/comment`로 남긴 답변과 `/sys` 내레이터 메시지도 검색돼요. 범위 칸의 **QR·코멘트**를 고르면 그것만 찾아요. `<details>`로 접힌 내용도 찾고, 결과를 누르면 접힌 답변이 **펼쳐지면서** 그 자리로 가요. 오래된 메시지로 갈 때도 한 번에 불러오고, 도착한 뒤 잠깐 그 자리를 붙잡아 둬서 화면이 맨 아래로 튕겨 내려가지 않아요. 답변 속 `<style>`·`<script>` 코드는 검색에서 빠져요 |
| 별점 · 한줄평 | 독서노트·목차 탭 맨 위 "이 책의 별점"을 눌러 이 채팅에 별 5개 + 한줄평. 목차의 ☆로 챕터마다도 남길 수 있어요 |
| 스크랩북 | 독서노트 탭 **고르기** → 노트 여러 개 선택 → **스크랩북에 담기**. 선반의 스크랩북을 누르면 모아 보기 · 이름 바꾸기 · 카드 한 장으로 |
| 카드로 모으기 | 노트 여러 개를 골라 명대사 카드 한 장에 담아요 |
| 카드 여러 장 | 스크랩북이나 고른 노트로 **카드 만들기** → **여러 장으로**. 노트마다 한 장씩 같은 디자인으로 만들고, 장 번호(1 / 5)를 붙여 **한꺼번에 저장**해요. 휴대폰에서는 **공유**로 한 번에 보낼 수 있어요 |
| 챕터 요약 카드 | 목차에서 챕터의 🖼 버튼. 챕터 제목·별점·한줄평에 그 장의 문장 3개까지 담아요(메모 단 문장이 먼저 골라져요). 칠한 문장이 없으면 그 장의 첫머리가 들어가요 |
| 독서 기록 카드 | 통계 탭의 **이 기록을 카드로 만들기**. 먹은 쪽수, 메시지 수, 함께한 날, 형광펜·책갈피 수, 자주 나온 단어, 별점을 한 장에 |
| 오늘의 문장 | 패널 맨 위에 예전에 칠한 문장 하나를 띄워요. 하루 동안 같은 문장이고 ↻로 다른 문장, ✕로 오늘은 그만. 누르면 그 자리로 가요. 설정에서 끌 수 있어요 |
| 노트 태그 | 메모에 `#설렘`처럼 쓰면 태그가 돼요. 노트 탭의 태그를 눌러 모아 보고, 검색 탭에 `#설렘`을 쳐도 돼요. 메모 창에서 쓰던 태그를 눌러 바로 붙여요 |
| 책갈피 폴더 · 순서 | 책갈피의 📁 버튼으로 폴더에 넣고, 폴더 이름을 눌러 접고 펴요. **내 순서**로 바꾸면 손잡이를 끌어 순서를 바꾸거나 다른 폴더로 옮겨요(마우스·손가락 모두) |
| 서재 (채팅 넘나들기) | **서재** 탭에서 이 캐릭터와 나눈 다른 채팅들의 노트·책갈피를 한곳에 모아 보고 찾아요. 누르면 그 채팅이 열리고 그 자리로 가요. 그룹 채팅은 아직 안 돼요 |
| 여우의 보관함 | 책갈피·노트·챕터·스크랩북을 지우면 바로 사라지지 않고 보관함으로 가요. 패널 머리의 📦 버튼(숫자 = 보관 중인 개수)에서 **되돌리기 / 모두 되돌리기 / 영구 삭제 / 보관함 비우기**. 지운 직후 뜨는 알림을 눌러도 되돌려져요. 노트를 되돌리면 담겨 있던 스크랩북에도 다시 들어가요. 최근 300개까지 보관해요 |
| 내보내기 | 패널 머리의 📤 → 마크다운 / 백업(JSON) / 불러오기 (별점·스크랩북도 들어가요) |

## 설정 (확장 패널 → 🦊 책 먹는 여우)

- 패널 테마: 자동(SillyTavern 밝기에 맞춤) · 밤의 서재 · 아침 서재 · SillyTavern 테마 색 그대로
- 채팅에 형광펜 · 메모 밑줄 · 챕터 구분선 · 책갈피 리본 보이기
- 형광펜 색상 4개, 페이지 환산 기준 (기본 1쪽 = 600자)

책갈피와 노트는 **채팅마다 따로** 저장됩니다(채팅 파일의 메타데이터).
