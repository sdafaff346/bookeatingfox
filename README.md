# 🦊 책 먹는 여우 (Book-Eating Fox) for SillyTavern

채팅을 한 권의 책처럼 읽게 해주는 확장입니다. 책갈피, 리디 스타일 독서노트, 챕터와 목차, 채팅 검색, 독서 통계, 명대사 카드, 내보내기를 여우가 챙겨줍니다.
외부 라이브러리 없이 파일 3개로 만들었습니다. 따로 웹폰트를 받지 않고, 쓰고 있는 테마(SillyTavern 테마, 블루 레몬에이드 같은 테마 확장)의 글꼴과 글자 크기를 그대로 따라갑니다. 노트 인용문과 명대사 카드는 채팅 본문과 같은 글꼴로 보여요.

## 설치

**SillyTavern 확장 설치 기능으로 (추천)**

1. SillyTavern 위쪽 메뉴의 **확장(퍼즐 조각) → Install extension**을 누르세요.
2. 아래 주소를 붙여 넣고 **Install**(관리자 계정이면 Install just for me)를 누르세요.
   ```
   https://github.com/sdafaff346/bookeatingfox.git
   ```
3. 설치가 끝나면 새로고침하고, **마법봉 메뉴 → 책 먹는 여우**로 패널을 여세요.
4. 업데이트는 확장 관리(Manage extensions)에서 책 먹는 여우 옆 업데이트 버튼으로 할 수 있어요.

**직접 넣기**

1. [GitHub 저장소](https://github.com/sdafaff346/bookeatingfox)에서 Code → Download ZIP으로 받아 압축을 푸세요.
2. 폴더를 통째로 `SillyTavern/data/default-user/extensions/`(내 계정만) 또는 `SillyTavern/public/scripts/extensions/third-party/`(모든 사용자)에 넣고 새로고침하세요.

예전 `SillyTavern-Bookshelf`(책갈피) 폴더가 있다면 지우세요. 저장된 책갈피와 노트는 그대로 이어집니다.

## 패널 열기와 옮기기

- 입력창 왼쪽 **마법봉 메뉴 → 책 먹는 여우**를 누르면 패널이 열려요. (`/bookfox`로도 열 수 있어요)
- **PC**: 패널 윗부분을 끌어서 옮기고, 오른쪽 아래 모서리를 끌어서 크기를 바꿔요. 윗부분을 더블클릭하면 원래 자리로 돌아가요.
- **모바일**: 화면 전체를 쓰는 창으로 열려요. 왼쪽 위 ‹ 버튼으로 채팅으로 돌아가고, 목록에서 항목을 누르면 창이 닫히면서 그 메시지로 이동해요.
- 위치와 크기는 기억돼요. 설정의 "패널 위치·크기 초기화" 버튼으로 되돌릴 수 있어요.

## 기능

| 하고 싶은 것 | 방법 |
|---|---|
| 책갈피 | 메시지 `⋯` → 🔖 버튼 (다시 누르면 빼기) · `/bm 이름` |
| 형광펜 | 채팅에서 문장이나 문단을 드래그한 뒤 색 선택 (채팅에 보이는 줄바꿈·문단 나눔 그대로 저장돼요) |
| 형광펜 없이 메모 | 드래그한 뒤 **메모** 선택. 메시지 전체에 메모하려면 `⋯` → 📝 |
| 형광펜 색 바꾸기 / 지우기 | 칠한 문장을 누르세요 (⌀ = 형광펜 없이 메모만 남기기) |
| 챕터 시작 | 메시지 `⋯` → 📖 버튼, 또는 목차 탭에서 추가 |
| 명대사 카드 | 드래그 → **카드**, 또는 메시지 `⋯` → ❝ (여우·밤숲 등 7가지 테마, 여우 도장). **원문 줄바꿈 / 문장마다 / 한 문단** 버튼으로 줄을 정리하고, 엔터·빈 줄로 직접 나눌 수 있어요 |
| 원문 + 번역 카드 | 카드의 **번역** 칸에 번역 문장을 적으면 원문 아래(또는 위)에 작게 함께 들어가요. 실리태번 번역 기능을 쓰는 메시지는 **메시지의 다른 언어 불러오기**로 한 번에 채워요. 번역은 노트에도 저장돼 목록·내보내기에 같이 나와요 |
| 별점 · 한줄평 | 독서노트·목차 탭 맨 위 "이 책의 별점"을 눌러 이 채팅에 별 5개 + 한줄평. 목차의 ☆로 챕터마다도 남길 수 있어요 |
| 스크랩북 | 독서노트 탭 **고르기** → 노트 여러 개 선택 → **스크랩북에 담기**. 선반의 스크랩북을 누르면 모아 보기 · 이름 바꾸기 · 카드 한 장으로 |
| 카드로 모으기 | 노트 여러 개를 골라 명대사 카드 한 장에 담아요 |
| 내보내기 | 패널 머리의 📤 → 마크다운 / 백업(JSON) / 불러오기 (별점·스크랩북도 들어가요) |

## 설정 (확장 패널 → 🦊 책 먹는 여우)

- 패널 테마: 자동(SillyTavern 밝기에 맞춤) · 밤의 서재 · 아침 서재 · SillyTavern 테마 색 그대로
- 채팅에 형광펜 · 메모 밑줄 · 챕터 구분선 · 책갈피 리본 보이기
- 형광펜 색상 4개, 페이지 환산 기준 (기본 1쪽 = 600자)

책갈피와 노트는 **채팅마다 따로** 저장됩니다(채팅 파일의 메타데이터).
